# Exercise UI Symbols

When solving exercise, quiz, listening, fill-in-the-blank, or practice screens, inspect the UI symbols and blanks carefully before acting.

Important rules:

- A yellow arrow pointing left is not a Back button and not a Submit/Next button. Treat it as Delete/Backspace for removing an answer or character.
- Before answering fill-in-the-blank questions, count how many visible blanks or underline groups there are.
- Multiple connected underlines often mean the answer is a phrase, not a single word.
- Do not tap the yellow left arrow unless the task requires deleting the current input.
- If the screen has several blanks, fill answers in the correct order and avoid submitting after only one blank unless the UI clearly asks for one answer.

For uncertain exercise screens, prefer observing the screenshot and using audio/reasoning context before clicking destructive controls.
